# Ideas

A backlog of possible changes to how this vault works, usually prompted by something a source describes.
The wiki records what sources say; this file records what that might mean for the vault itself.
Adopting an idea goes through the normal rule-change process (`meta/Schema.md` plus a `meta/Decisions.md` entry).

Format: `## Idea`, then **From** (source page), **What**, **Status** (`open` / `adopted (D-NNN)` / `rejected (reason)`).
